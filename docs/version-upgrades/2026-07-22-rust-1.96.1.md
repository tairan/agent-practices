# Rust 1.96.1 基线升级记录

- 日期：2026-07-22
- 旧版本：`1.96.0`
- 新版本：`1.96.1`
- 变更类型：安全与正确性补丁升级
- 影响范围：技术基线、`structured-output` 代表性概念

## 原因

Rust `1.96.1` 修复同系列错误编译、Cargo HTTP 和 libssh2 安全问题。依据：[Rust 1.96.1 官方公告](https://blog.rust-lang.org/2026/06/30/Rust-1.96.1/)。

## 兼容性与验证

- Edition 与 resolver 不变。
- 直接依赖和 `Cargo.lock` 不变。
- `structured-output` 在 `1.96.1` 下通过 `cargo test --locked`。
- `structured-output` 在 `1.96.1` 下通过 `cargo clippy --locked --all-targets --all-features -- -D warnings`。
- 回滚方式：仅在明确接受已知安全与正确性风险后，把技术基线、项目 `rust-toolchain.toml` 和 `rust-version` 一致恢复为 `1.96.0`；不得只回滚其中一处。

该升级作为独立版本决策记录，不改变 profile、能力标准、安全不变量或项目范围。

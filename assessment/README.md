# 能力验收

本目录把“完成项目”与“证明能力”分开。

- [`rubric.md`](rubric.md)：能力域、L0-L4 行为锚点、阶段门禁和 Capstone 评分。
- [`blind-task-protocol.md`](blind-task-protocol.md)：未知任务、故障和攻击样本的隔离与复核方式。

## 验收流程

1. 学习者使用 [`../templates/evidence-index.md`](../templates/evidence-index.md) 提交项目声明、预注册验收契约和 evidence 索引。
2. 评审者确认目标能力域和当前等级，不以项目数量替代判断。
3. 先复核公开测试、评测统计、安全不变量和决策记录。
4. 再按盲测协议执行未知任务、未知故障或未知攻击，并使用 [`../templates/blind-task-report.md`](../templates/blind-task-report.md) 留痕。
5. 记录观察事实、等级判定、未满足行为和复核者身份。
6. 能力升级只基于本次 evidence，不根据简历、自报熟练度或代码量推断。
